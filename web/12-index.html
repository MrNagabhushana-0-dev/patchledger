Checks, privacy and limitations

Checks cover dynamic evaluation, process execution, raw HTML sinks, disabled TLS verification and unfinished-work markers. They are text matches, not language-aware analysis. A source line can trigger more than one rule. Large finding lists are capped and labelled.

Folder import skips dependency/generated directories, unsupported file types and known credential filenames before reading them. Selected files still pass local content checks. This does not detect every secret. Closing or refreshing clears the source and notes. Unsaved assessments trigger a browser warning where supported.

The browser-local workbench does not run AI inference.
