Checks, privacy and limitations

Checks cover dynamic evaluation, process execution, raw HTML sinks, disabled TLS verification, possible hardcoded credentials, weak hash functions, non-cryptographic randomness and unfinished-work markers. They are text matches, not language-aware analysis. A source line can trigger more than one rule. Large finding lists are capped and labelled.

Version comparison pairs files by path and classifies each as added, modified, unchanged or removed from SHA-256 fingerprints. A moved or renamed file reads as one removal and one addition. Folder import skips dependency/generated directories, unsupported file types and known credential filenames before reading them. Selected files still pass local content checks. This does not detect every secret. Closing or refreshing clears the source and notes. Unsaved assessments trigger a browser warning where supported.

The hero scene and the review map are WebGL drawings rendered in this tab from local data. They are visual navigation, not analysis: every finding still comes from the text checks and your decisions. If WebGL is unavailable, the explorer and queue work unchanged. Animations stop when reduced motion is preferred.

The browser-local workbench does not run AI inference.
